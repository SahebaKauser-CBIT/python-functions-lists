# Python Functions and Lists

## Project Overview
This project demonstrates Python functions and list operations through an interactive command-line Item Manager.

## Features
- Add items to a list.
- View all stored items.
- Delete existing items.
- Handle empty input and invalid menu choices.
- Use reusable functions and Python lists.

## Requirements
- Python 3.8 or later

## How to Run
Open a terminal in the project root and execute:

```bash
python -m src.main
```

## How to Run Tests
```bash
python -m unittest discover -s tests
```
